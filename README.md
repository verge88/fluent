# Fluent

Сайт для изучения английского языка в современном монохромном дизайне. Интерфейс на русском, учебные материалы на английском с переводом.

## Возможности

- 12 интерактивных уроков уровней A1–B1: объяснения, примеры и задания.
- 36 слов с транскрипцией, переводом, примерами и озвучкой.
- Личный словарь и карточки для повторения.
- Аудирование, практика грамматики и ориентировочный тест уровня.
- Ежедневная цель, прогресс и достижения.
- Экспорт и восстановление прогресса из JSON-файла.
- Адаптивная версия для телефона.

## Запуск

Сайт работает без сборки и установки зависимостей. Для локального запуска откройте терминал в папке проекта:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080 в браузере.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем сохраните. После успешной публикации адрес будет показан в разделе Pages.

## Данные и озвучка

Прогресс хранится локально в браузере через localStorage. Автоматической синхронизации между устройствами нет; для переноса используйте экспорт и восстановление в настройках сайта. При смене адреса сайта данные автоматически не переносятся.

Озвучка использует Web Speech API и доступные голоса браузера или операционной системы. Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты. Сервер, база данных и секретные ключи не требуются.

## Файлы

- `index.html` — разметка сайта.
- `style.css` — монохромный дизайн и адаптивная вёрстка.
- `app.js` — материалы, упражнения и сохранение прогресса.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.
